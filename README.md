# 🚢 Gjøvikmillionæren 3D – Den Hvite By ved Mjøsa

Et fullverdig 3D-brettspill i nettleseren inspirert av Monopol og Millionær, lagt til gater, nabolag og kjente landemerker i **Gjøvik**!

## ✨ Funksjoner
- **3D-brett med Gjøvik-landemerker (Three.js):**
  - **DS Skibladner (1856/1888)** på bølgene i Mjøsa med svarte skovlhjulhus, messingfløyte, salongdekk og skorstein.
  - **Fastland Friluftsbad** med det ikoniske hvite funkis-stupetårnet fra 1947 (5m og 10m plattform + 1m og 3m sviktbrett).
  - **Hovdetoppen & Fjellhallen** (med Arresten inne i fjellet), **Gjøvik Gård**, og **Gjøvik Chokoladefabrikk**.
- **2–6 Spillere (Lokalt & Robot/AI):**
  - Spill lokalt (bytt sete) eller mot datastyrte **Robot/AI-spillere** med tre vanskelighetsgrader (*Lett: Turist på Skibladner*, *Middels: Kremmer i Storgata*, *Vanskelig: Eiendomsbaron på Hovdetoppen*).
- **Valgfrie Husregler ved oppstart:**
  - *Klassisk Monopol (Standard)*: Må eie hele fargeserien før du kan bygge, og må bygge jevnt.
  - *Klassisk – Fri utbygging i eid serie*: Må eie hele fargeserien, men kan bygge fritt innenfor serien.
  - *Gjøvik-regelen*: Bygg hus med én gang på enhver gate du eier.
  - Valgfri Fastland-pott, dobbel lønn (kr 8 000) ved landing midt på START, og tvungen auksjon.
- **44 humoristiske lokale kort:**
  - 22 **Byavisa**-kort og 22 **Mjøsgløtt**-kort fulle av lokal Gjøvik-humor.

## 🚀 Spill direkte eller lokalt
Åpne `index.html` via en lokal webserver, for eksempel:
```bash
python3 -m http.server 8080
```
Og gå til `http://localhost:8080` i nettleseren.
